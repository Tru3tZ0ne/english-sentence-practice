## 怎么练

重启应用后，前 10 张卡片仍按“小学 → 初中 → 高中 → 四级 → 六级”排列；随后是上表 12 张语法卡片，再后面是原有主题题库。点击对应卡片即可练习，子主题显示在题目标签中。

建议从“冠词与数量 → 位置介词 → 指代与一致 → 比较”建立基础，再练“搭配介词 → 定语和状语从句 → 不定式与动名词”，最后进入“名词性从句 → 分词与逻辑主语 → 否定范围 → 强调与倒装”。也可以直接选择自己经常出错的专项。

每次按一个子主题练 10 题：先根据中文组织句子，再看讲解定位错误，最后回到生活或议论题库运用。同一语法点的重点是理解关系与含义，例如 by 与 until 的期限区别、关系词在从句中的成分、only 的位置如何改变焦点，而不只是背诵连接词。

现有练习形式仍是中译英和已列答案比对，不是选择题或自动语义判分。合理但未列入 `answers` 的译法可能不会判为正确。本轮 720 题共有 **813 个答案条目**，包括缩写等变体；这些变体没有计为新题。

## 如何控制同质化

新增句子从不同的表达任务出发，覆盖路径描述、物品辨认、原因解释、条件限制、责任判断、比较范围、语气与信息焦点，并逐题写出中英文和语法讲解。复核同时关注句式、情境和训练目的，发现与旧题目的过近的题目后进行重写。

少量语法对照有意保留，例如 `Only my sister ...` 限定“谁知道”，而 `... knows only the location ...` 限定“知道什么”；`most of the bread is` 与 `most of the rolls are` 用来说明可数性怎样影响谓语数。它们有具体的教学差异，不把任意更换人物、名词或数字作为扩题方法。

本轮跨全库筛查并复核结果如下，详细候选及保留理由见 [审校记录](_quality/grammar-audit.json)。

| 检查 | 结果与口径 |
| --- | --- |
| 英文完全重复 | 全库 0 对；小写词序列，忽略标点与多余空白 |
| 仅替换一个词 | 全库 0 对；至少 5 词、词数相同 |
| 仅增加或删除一个词 | 全库 0 对；较短句至少 5 词 |
| 新题近似句 | 0 对；涉及新增题、共享连续两词、至少 5 词、词序列相似度 ≥ 0.75 |
| 中文完全重复 | 涉及新增题 0 对；去除标点后比较 |
| 松散英文词汇重合 | 9 个候选；加权词汇余弦相似度 ≥ 0.45 |
| 中文双字词组重合 | 3 个候选；加权余弦相似度 ≥ 0.40 |
| 词汇重合候选复核 | 两项筛查合并去重后 11 对，逐对记录保留理由 |
| 新库最常见前四词占比 | 最高 1/60，约 1.67%；没有触发 15% 复核线 |
| 答案变体跨题重复 | 涉及新增题 0 对；按现有答案归一化规则比较 |

词汇及句式筛查不能证明不存在任何语义重合，也不能验证所有语法和翻译。新增题另行进行了中英对应、自然表达、逻辑关系和学习价值的编辑审校。重复语法知识可以帮助巩固，但每题仍应有明确的练习用途。
