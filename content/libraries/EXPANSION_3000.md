## 改进方式与完成情况

| 问题 | 已完成的改进 |
| --- | --- |
| 题量不足 | 增加具体使用场景、论证主题与书面表达任务，达到 3,000 题。 |
| 换词或换数字形成新题 | 逐题编写，检查完全重复、单词替换、单词增删及近似句；改写命中或人工发现的相近训练任务。 |
| 场景不同但训练目的雷同 | 会话侧重请求、解释、协调、澄清与跟进；议论侧重机制、条件、权衡、反例与评价边界。复核时同时检查跨库的概念重合。 |
| 图表题反复套用涨跌数字 | 增加数量与占比、百分点、组内比例、分布、平均数与中位数、实测与预测、缺失数据、流程分支、循环和地图功能变化。所有数值均为虚拟练习设定。 |
| 单句无法练习论证衔接 | 段落库扩至 96 题，使用相连句子练习指代、举例、因果、让步、前提、对照、替代解释及行动结论。 |
| 中文信息漏译、英文搭配生硬 | 复核并修正比较对象、事件先后、否定范围、授权边界和自然搭配。例如区分 public interest（公共利益）与 public curiosity（公众好奇心），以及 food security 与 food safety。 |
| 难度标注过于粗糙 | 普通议论句与多层论证分开标注；叙事中的完成时、持续时态、倒装和嵌套从句另行调整。每道新增题都有讲解、主题及子场景标签。 |

例如，图表题没有再增加另一道同结构的“八月达到年度峰值”，而是改为描述“夏季高峰后，到十一月已回落至一月水平”。社区题也不只写“试行一个月”，而是练习轮流承担公共活动室锁门责任及其理由。

同一种语法或常用搭配可以在不同任务中复现。例如，“请不必等我”与“我可以陪你等一会儿”分别用于免除等待和提供陪伴，交际角色及意图不同。复现不等于重复计数；仍需判断每题是否带来新的学习任务。

- `.venv\Scripts\python.exe tools\validate_libraries.py`：**44 个题库全部通过**。
- 实际加载结果：**3,000 题**；所有标题中的数量与实际一致。
- 原有 **1,202 个题目对象**逐项保持一致，包括 ID、中英文、答案、讲解、标签和难度。
- 全库英文按小写词序列、忽略标点与多余空格检查：完全重复 **0 对**。
- 至少 5 词、词数相同且仅替换一个词：**0 对**。
- 仅增加或删除一个词，较短句至少 5 词：**0 对**。
- 共享连续四词、至少八词、词序列相似度不低于 0.78 的候选：**0 对**。
- 补充短句筛查：至少五词、共享连续两词、词序列相似度不低于 0.75，涉及新增题的候选：**0 对**。
- 补充不计词序的词汇重合筛查并人工复核：保留 **2 对**有独立交际任务的常用表达，具体理由见审校记录。
- 各库最常见的前四词占比最高约 **5.56%**，低于 15% 的复核阈值。
- **3,468 个已列出的答案**均通过现有答案比对；标准英文均在 `answers` 中。共有 464 题提供答案变体。

以上相似度指标是筛查工具，不是“完全没有语义同质化”的证明，也不验证所有语法或翻译。新增内容另行进行了中英对应、自然表达、任务差异和论证关系的编辑复核。项目仍按已列出的答案比对，并非开放式语义判分。
